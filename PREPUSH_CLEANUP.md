# RH Habits — Pre-push cleanup

Canonical web source lives in the repository root.
`www/` is generated by `npm run native:prepare` and must not be committed.

Keep only `Code.gs` as the canonical Apps Script source. Remove lowercase `code.gs` from GitHub and remove `maps-helpers.gs` if the Apps Script project uses the fixed `Code.gs`, because the Maps helper functions are already included there.

Do not commit `node_modules/`.
