WHY THIS FIX
- Restores renderTrend/renderPublicTransport (the exact desktop error was caused by those App methods missing).
- Vercel no longer rewrites directly to stale Apps Script; /api/rpc is now a real proxy with CORS + OPTIONS handling and the latest GAS deployment.
- Native GPS POST uses latest GAS deployment.
- Speed uses native/OS speed when valid, otherwise segment-distance/time fallback; no display smoothing.
- Trip Save retains movingTimeMin/stopTimeMin/stopCount/routeVariant.
- Saved GPS compression keeps up to 900 representative points instead of every fifth point, reducing route jumps.
- Map can request getTripGpsPoints() and renders actual stored points with Leaflet.
- iOS date inputs are width constrained to prevent the control from overflowing the column.
- OCR uses native Camera/Photos on native builds and the same analyzeReceipt() backend path.
- App.error no longer falsely marks the whole backend offline on OCR/GPS/UI errors.

IMPORTANT LIMIT
No software can force iOS to deliver GPS after the user explicitly terminates the app or disables location services. Background tracking depends on iOS permission/capability and system policy. The app can keep recording while locked/backgrounded when properly configured and the OS continues the location session.
